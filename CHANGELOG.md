# Release log

All notable changes to Tabloop (called Feedpak Player up to 0.9.1), newest first. Each version is published to https://tabloop.github.io/ (also downloadable as a single `index.html`).

## 0.58.0 — 2026-11-12

### Added (unclear notes confirmed by their harmonics, F-74, branch `detect/harmonic-confirm`)
- **`harmonics.ts` `harmonicCheck`**: when YIN's reading of a note is unclear, or more than 50 ¢ from the tab's note (octaves folded; `noteDetect.ts HARM_CHECK_CENTS`), the onset window's spectrum (from 15 ms after the onset, up to 160 ms or the next onset; 24 kHz, Hann, zero-padded to 8192 points with onsets.ts's FFT, now exported and cached per size) is checked for the EXPECTED note's partials 1–8 up to 5 kHz (±35 ¢, stretched sharp up to B = 3·10⁻⁴ for a string's inharmonicity). A partial's strength: its prominence over ±half a partial spacing (6 dB → 0, 18 dB → full) × its level (1 at the spectrum's loudest, 0 at 40 dB under it); 0 when a peak beside it is 20 dB louder (a side lobe). Rivals: ±1 / ±2 semitones, fifth and fourth up and down, octave up and down, twelfth down, YIN's reading — against each, the partials that aren't shared: the expected note's own must score 1.6 × the rival's own (all of its partials when it has no own ones: a rival below it); an octave up has no own partials, so the odd ones must score 0.5 × the even ones. At least 3 partials found, a score ≥ 0.6. The last note's partials (its `ref`: the reading, or its tab note when that was unclear) are left out; when that leaves fewer than 3 (the same note again) only a firm onset counts. The partials must rise 3 dB on average over the same length just before the onset (a note played, not one still ringing). Confirmed: the pitch from the partials (strength-weighted cents of partials 1–6: flat / sharp still judged), `est.harmonic`, aperiodicity set to `UNCLEAR_AP` (🔍 Check my input shows *by its harmonics* instead of *% clear*). ~0.3 ms per check, only for unclear / far-off readings.
- Only for the onset kept for its tab note (`nearestTo`): `noteAt(…, harm, prevRef)` with `harmMode(keep, k, item)` — `firm`, `informed` (the onset found only by `pickOnsetItems`' lower thresholds near the tab note: `Item.informed`, new) or `off`. Takes (`takesView.ts measure`), 👂 Live (`liveGhost.ts`), 🔍 Check my input and the 🔬 Detect Lab (`web/lab/assess.ts`) all go through it; ✎ Transcribe doesn't (no expected notes); chords aren't checked (F-73).
- Judged as any reading (`PlayedNote.harmonic` → `Ghost.harmonic`); the hint card's Pitch row adds *by its harmonics*; the Detect Lab's detection tooltip too. `notANote` (echoes, the same note again) compares an extra onset with what YIN read for a harmonically confirmed note (`DetectedNote.yin`), so echo handling is as before.
- **Detect Lab**: `harmonics.ts` is a tunable module (`tools/lab-tunables.mjs`); sweep entries `harmonics.HARM_MARGIN / CENTS / K / MIN / SCORE / PROM / RANGE / ODD / RISE / WIN / FMAX`, `noteDetect.HARM_CHECK_CENTS`, `onsets.SAT / SAT_AP`; its own group in the lab's settings.

### Fixed
- **B-16: a distorted take's notes found up to 23 ms early** (e2e-takes-feedback: *2/8 notes found on time*). The pitch was right; with the previous note still sounding through a clipping distortion the level never rises, so the energy onset's quarter-of-the-rise placement fired at the start of its search window. `onsets.ts refineQuarter`: when the level before is ≥ 0.9 × the peak and the RMS doesn't rise (`SAT`), the onset is where the waveform stops repeating the last note's period (`periodicBreak`: the period over the 10 ms before, normalised difference ≤ 0.2; the first sample whose difference from one period earlier stands out), searched 25 ms further; else as before. Energy and informed-rise onsets only (not a flux onset's few ms). The distorted take: 8/8 on time; fast picked runs' onsets 7 ms → 0 ms off.

### Changed (a better tab synth, F-72 steps 1–2, branch `audio/synth-v2`)
- **Strings — extended Karplus–Strong (Jaffe–Smith)** (`synth.ts`, all on the audio thread as before, so speed, loops, seek, Pitch and the mixer work unchanged): the pluck is a one-period noise burst through a one-pole low-pass (brightness: accents ×0.45 smoothing, MIDI velocity, slap / pop brighter, palm mutes / fingered bass / harmonics darker) and a **pick-position comb** `x[k] − x[k − βP]` (β 0.11–0.19 for a pick, varying per note; 0.2–0.26 for bass; 0.05–0.07, near the bridge, for a palm mute), scaled to the v1 burst's level for the same kind of note. **Stiffness**: a first-order dispersion allpass in the loop for wound strings (guitar strings under 165 Hz: a = −0.14; bass: −0.3), its phase delay at the fundamental tuned out in `lenFor` (offline: every mode within 0.5 ¢). **Decay per string**: bass rings longer (T60 min(4.5, 1.6 + 220/f) s); palm mutes 0.11 + 10/f s, with an extra one-pole low-pass in the loop (the palm on the string; its delay tuned out too) and the darkest two-tap blend.
- **Harmonics** are a string at the harmonic's pitch (natural: a bright loop, a mostly-fundamental burst, 2.6 s; pinch: brighter, 1.4 s) instead of the 3-partial additive bell; a harmonic held past its default 0.8 s uses the sustain mode (B-12) like any string. Hammer-ons don't continue a harmonic's voice.
- **Bass voice** (`PluckSynth(sr, { bass })`; the engine sets it per part from the tone): rounder pluck, longer ring, stiffer strings. **Slap / pop** (`slp` / `plk`, new flags `F_SLAP` = 256, `F_POP` = 512; the notes' flags are `Uint16Array` now): slap = a bright short burst + a low thump (260 Hz low-passed noise, 14 ms), pop = a very bright burst + a click (high-passed noise, 4 ms), both with a brighter sustain. `main.ts sendNotes` and ▶ Hear it (`noteCard.ts`) set them.
- **Per-part tone** (`synthfx.ts`, new; `PartFx` per tab part in the worklet, the part rendered mono, then panned): **acoustic** — four damped body resonances (102 / 196 / 390 / 920 Hz) added to the string, HP 60 Hz, a little 3.2 kHz; **clean** (also any guitar part without a hint) — a little body, HP 70 Hz, a +3 dB pickup peak at 2.6 kHz, LP 6.5 kHz; **electric** — HP 110 Hz and a +2 dB 800 Hz push before the amp, pre-gain 3.2 into an asymmetric tanh (bias 0.18), 2× oversampled (midpoint + half-band average), then a cab: HP 80 Hz, +4 dB presence at 2.5 kHz, LP 5.5 kHz + 8 kHz (24 dB/oct above 8 kHz; a single steep 5 kHz pair cost the pick attack too much — e2e-synth-techniques' picked-note check), make-up 1 (each part's RMS = v1's); **bass** — HP 35 Hz, +2 dB low shelf at 110 Hz, drive 1.3 (barely), LP 3.8 kHz. Which one: `partTone(info, bass, tone)` — bass parts → bass; acoustic / nylon / classical… in the name or tone → acoustic; then the pack's tone name (§6.9 `tones.base`, read now as `Arrangement.tone`, the manifest entry's `tones.base` first): clean / jazz → clean, dist / drive / crunch / metal / lead… → electric; then the part's name (Clean… → clean; Lead / Rhythm / Electric / Distortion… → electric); else clean.
- **Stereo**: `partPans` — bass and a single guitar in the middle; two or more guitar parts alternate right / left at ±0.28 (more parts a little wider, ≤ 0.45), balance law (the middle is unchanged; a side only turns the other side down). Sent with the notes (`notes.tone` / `notes.pan`).
- **Reverb** on the tab synth bus only (and ▶ Hear it's own): a 4-line FDN (29.7–47.9 ms, Hadamard, damped at 4.5 kHz, T60 1 s), fed above 250 Hz (bass and chugs stay dry), 12 ms pre-delay, wet 0.1. It stops working after 2 s of silence, and is cleared at a seek / stop / the channel off.
- **Drums** (`drumsynth.ts`): hi-hat / ride / crash — six square oscillators at the 808's ratios (205.3–800 Hz, scaled per cymbal) + a little noise (more for the crash) through a band-pass (8.8 / 5.2 / 6.5 kHz, higher for harder hits) and a high-pass, a ride bell (2.65 + 3.97 kHz); open hi-hat and crash ring longer the harder they're hit. Snare — a two-mode pitched body (180 / 330 Hz with a 12 ms pitch drop) and band-passed noise wires (3.2–5.4 kHz with velocity; more wires and a longer tail for harder hits). Kick — a sine dropping from 140–230 Hz (harder: higher) to 48 Hz, a band-passed click (2.5 ms, louder when harder), soft saturation. Toms — a bigger pitch drop and a stick click for harder hits. Every voice ends with a 5 ms fade. Levels matched to v1 per piece (RMS over the first 100 ms within ~1–2 dB at velocity 127).
- **Levels** (`tools/bench-synth.mjs`, Whiskey in the Jar 60–120 s: lead + rhythm + bass, ~5300 notes): synth bus (before the channel gain) peak v1 +1.4 dBFS → v2 −1.8 dBFS, RMS −18.8 → −19.4 dBFS; per part the RMS is within 0.1 dB of v1 (the amp's make-up), the peaks 4 dB lower (the amp's lower crest factor). Ghost — Peacefield 120–180 s: peak −0.9 → −4.0 dBFS, RMS −22.0 → −22.1 dBFS. The A/B clips: within ~2 dB RMS of v1 (single electric notes / chugs 1.7–2 dB under).
- **CPU** (same bench, Node 24 / V8, the worklet's code and quanta): Whiskey 60–120 s (up to 20 voices) 7.7–8.9 → 11.2–11.6 ms of CPU per second of audio (≈ 0.8 → 1.15 % of one core, +35–45 %); the worst 128-frame quantum after warm-up 0.2–0.55 ms of its 2.67 ms either way; Peacefield 5.6 → 7.7 ms/s.
- **A/B (dev)**: `localStorage["tabloopSynth.v1"] = "1"` (or `window.__tabloopSynthV1 = true` before the song loads) plays the v1 strings and drums with no tone / stereo / reverb (the engine's new `synthV1` command; `synthCfg.v1` in `synth.ts`, read per note); `__feedpak.synthV1(true | false)` switches live (also for backing tracks generated afterwards). `tools/render-synth-compare.mjs` renders A/B clips (clean and acoustic riff, palm-muted chugs, bend + vibrato + harmonics, bass with slap / pop, a drum groove) to `builds/synth-compare/<clip>-v1.wav` / `-v2.wav` (not in git) with the app's own synth code, and prints each kit piece's level v1 vs v2.
